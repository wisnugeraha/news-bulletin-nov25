One broadsheet-style page that sums up Wednesday 25 November 2026: the Red Sea
escalation leads, six continental stories in a grid (Colombia hostage siege,
the Huawei verdict, Shenzhou-24's first Pakistani astronaut, California's
El Nino super-tides, Nvidia's CEO reversal, the AFCON title ruling), and a
wire strip of the day's other briefs. Drawn from that day's reporting; the
program delivers the page byte for byte to /output/entry.png.

## Run it

```sh
python3 main.py   # writes /output/entry.png
```
